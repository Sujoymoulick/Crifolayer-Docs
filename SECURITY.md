# Security Policy

## Supported Versions

The following versions of Crifolayer are currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a Vulnerability

We take the security of Crifolayer seriously. If you find any vulnerabilities or security issues in this documentation platform or core integration flows, please do not open a public issue.

Please report security issues privately by emailing **security@crifolayer.com**.

We will acknowledge receipt of your report within 48 hours and work with you to coordinate a fix and disclosure timeline.
